# ngitungrakaat
butuh inovasi biar ngitung sujud jadi ga lupa berapa rakaat

TUTORIAL:
1. pasang esp32 di breadboard
2. pasang resistor untuk led di pin GPIO32
3. hubungkan GND ESP32 dengan GND HC-SR04
4. hubungkan pin trig HC-SR04 dengan GPIO27 ESP32
5. untuk pin echo HC-SR04, dihubungkan dengan resistor 1 yang diconnect ke GPIO33, lalu resistor 2 ke GND ESP32
6. hubungkan VCC HC-SR04 ke pin 5V ESP32
